## Reddit r/SideProject

Title: I built a neon sign studio that glows as you type — free, offline, single HTML file

Body:
I wanted a neon sign for a mockup without paying a sign shop or signing up for another design tool — so I built Neon Mo.

- Type text, it glows instantly on a brick wall, dark wall, night sky or concrete
- 6 tube fonts, 10 neon colours, 3 tube styles, Steady / Pulse / Flicker animations
- 6 presets (OPEN, Café, Bar…) and a Shuffle button for instant inspiration
- Download as PNG — the export is rendered from the same canvas, so what you see is what you get
- Fully offline, single HTML file, MIT licensed — nothing leaves your browser

The core is free; Rainbow cycle animation + 2048px HD export are behind a shared OpenX Pro unlock. Demo + source: https://github.com/artzdesignmo/neon-mo (repo to be created — link once live)

Feedback welcome — which preset would you actually hang on your wall?
